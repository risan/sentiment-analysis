## One API, two languages

<div class="two-up">

```php title="English"
use Risan\Sentiment\Sentiment;

$result = Sentiment::analyze('Not bad at all!');

$result->isPositive(); // true
```

```php title="Indonesian"
use Risan\Sentiment\Language;
use Risan\Sentiment\Sentiment;

$result = Sentiment::analyze(
    'Filmnya bagus banget!',
    Language::Indonesian,
);

$result->isPositive(); // true
```
