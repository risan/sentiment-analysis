This page explains the numbers in a [`Result`](/reference/result/) and what changes them.

```php
$result = Sentiment::analyze('VADER is smart, handsome, and funny.');

$result->compound; // 0.8316
$result->positive; // 0.746
$result->neutral;  // 0.254
$result->negative; // 0.0
$result->label;    // Label::Positive
```

## Compound

`compound` is the one number to use when you want a single score. It runs from **-1** (extremely negative) to **+1** (extremely positive), with four decimals.

In the example, `0.8316` is close to +1. The text is clearly positive.

The package computes it in three steps:

1. Each word in the lexicon adds its score (-4 to +4). The rules below adjust it.
2. The package adds up the scores.
3. It squashes the sum so it always lands between -1 and +1.

Because of the last step, a compound of `0.5` does not mean "50% positive". Read it as a position on a scale. Near 0 is neutral. Near -1 or +1 is strong.

## Positive, neutral and negative

These three numbers are **shares** between 0 and 1, with three decimals. They add up to about 1.

In the example, 74.6% of the text is positive and none is negative. The other 25.4% is neutral: words with no sentiment, such as `VADER` and `is`.

They are not probabilities. A text with many neutral words and one mild positive word has a high `neutral` and still a positive `compound`. To decide, use `compound` or the label. Use the three shares to see how a text is built.

## Label

The [`Label`](/reference/label/) comes from `compound` and the [threshold](/guides/thresholds/):

| Condition | Label |
|---|---|
| `compound >= threshold` (and above 0) | `Label::Positive` |
| `compound <= -threshold` (and below 0) | `Label::Negative` |
| anything else | `Label::Neutral` |

The default threshold is `0.05`. The VADER authors recommend this value.

## What changes a score

The package does more than add up word scores. Here is how emphasis changes the compound score of the same word:

```php
Sentiment::analyze('not good')->compound;     // -0.3412
Sentiment::analyze('good')->compound;         // 0.4404
Sentiment::analyze('very good')->compound;    // 0.4927
Sentiment::analyze('VERY good!!!')->compound; // 0.7005
```

These are the rules:

| Rule | Example | Effect |
|---|---|---|
| Negation | `not good` | Flips the word and softens it |
| Intensifier | `very good`, `extremely bad` | Strengthens the word |
| Dampener | `kind of good`, `slightly bad` | Weakens the word |
| ALL CAPS | `this is GREAT` | Strengthens the shouted word |
| Exclamation marks | `great!!!` | Adds emphasis, up to 4 marks |
| Question marks | `great???` | Adds a little emphasis |
| Contrast | `good food but terrible service` | The part after "but" weighs more |
| Emoticons and emoji | `:)`, `❤️`, `😠` | Count as sentiment words |

Indonesian has the same rules. It also has intensifiers that come after the word (`bagus banget`), contrast words such as `tapi` and `namun`, and informal negations such as `gak`. See [Languages](/guides/languages/).

## Tips

- **Use the label to classify.** Use `compound` to rank.
- **Empty or whitespace-only text** gives all zeros and a neutral label.
- **Text with no known words** is neutral. The package only knows the words in its lexicon. [Add your own words](/guides/customizing-the-lexicon/) for slang from your field.
- **Long text** works better one sentence at a time. See [Long text](/guides/long-text/).
