The package scores English and Indonesian. English is the default.

```php
use Risan\Sentiment\Analyzer;
use Risan\Sentiment\Language;
use Risan\Sentiment\Sentiment;

// English
Sentiment::analyze('This is great!');

// Indonesian, by enum case or by code
Sentiment::analyze('Ini keren banget!', Language::Indonesian);
Sentiment::analyze('Ini keren banget!', 'id');

$analyzer = new Analyzer('id');
$analyzer->language(); // Language::Indonesian
```

Pick the language with the [`Language`](/reference/language/) enum or its string code:

| Language | Enum case | Code |
|---|---|---|
| English | `Language::English` | `'en'` |
| Indonesian | `Language::Indonesian` | `'id'` |

An unknown code throws a native `ValueError`:

```php
Sentiment::analyze('Hello', 'fr'); // throws ValueError
```

The package never guesses the language. If a text mixes languages, pick the main one. Or split the text and analyze each part with its own language.

## English

English uses the original **VADER** lexicon and the full VADER rules. The lexicon has about 7,500 words, emoticons and slang. Ten human judges rated each entry.

The package checks its scores against the reference implementation (`vaderSentiment` 3.3.2) on a large set of test sentences. You get the same numbers as the Python original, with two small differences on purpose:

- The "but" rule scales each part by position. The reference scales repeated equal scores wrongly.
- The package ignores the emoji variation selector (U+FE0F), so `❤️` scores like `❤`.

VADER was made for social media text. It also works well on reviews, comments and short messages.

## Indonesian

Indonesian runs on the same engine with its own data. Here are two examples:

```php
use Risan\Sentiment\Language;
use Risan\Sentiment\Sentiment;

$result = Sentiment::analyze('Filmnya bagus banget!', 'id');

$result->label;    // Label::Positive
$result->compound; // 0.623

$result = Sentiment::analyze('Pelayanannya lambat.', 'id');

$result->label;    // Label::Negative
$result->compound; // -0.4588
```

What the Indonesian data covers:

- **A lexicon** of Indonesian words with scores. It includes common affixed forms (`bahagia`, `membahagiakan`, `kekecewaan`) and informal spellings (`mantap`, `mantul`, `keren`, `zonk`).
- **Negations**: `tidak`, `tak`, `bukan`, `belum`, `jangan`, `tanpa`, `kurang`, and informal forms such as `gak`, `nggak`, `enggak`, `ga`, `tdk`.
- **Intensifiers before the word** (`sangat bagus`, `terlalu mahal`) and **after it** (`bagus banget`, `bagus sekali`, `keren parah`). Dampeners (`agak`, `cukup`, `kurang lebih`) work the same way.
- **Contrast words**: `tapi`, `tetapi`, `tp`, `namun`, `sayangnya`.
- **Suffixes and repeats**: the package strips `-nya`, `-lah`, `-kah` and `-pun` when the bare word is known. It looks up a repeated word such as `bagus-bagus` or `bagus2` as `bagus`.
- **Emoticons and emoji**, shared with English.

The Indonesian lexicon was written for this project and has the MIT license. No existing Indonesian sentiment list was copied, because the well-known ones have no open license. See [Credits & license](/credits/).

The baseline is the accuracy you get by always guessing the most common class. Compare it with the accuracy of the package.

A lexicon method does not match a fine-tuned neural model. The package publishes these numbers so you can judge for yourself.

### Known limits

- **Sarcasm and irony** are read at face value.
- **Regional languages** (Javanese, Sundanese and others) and heavy code-mixing are only partly covered. The Indonesian lexicon includes English words that are common in Indonesian reviews (`good`, `best`, `worst`). It does not fall back to the whole English lexicon. On the SmSA validation split, that fallback did not improve the macro F1, because many English words are also ordinary Indonesian words (`sore`, `alas`, `no`).
- **Words from your field**, such as product names or medical and legal terms, are missing unless you [add them](/guides/customizing-the-lexicon/).
- **Words are not stemmed.** An affixed form must be in the lexicon to be found, so rare forms can be missed.
- **Ambiguous words** get a careful score or are left out. For example, `parah` ("severe") is negative on its own. After another sentiment word it is an intensifier, as in `keren parah`.
