This page shows the basics in five short steps. Each step builds on the one before.

## Analyze a text

```php
use Risan\Sentiment\Sentiment;

$result = Sentiment::analyze('This package is awesome!');

$result->label;    // Label::Positive
$result->compound; // 0.6588
```

`Sentiment::analyze()` is the shortest way to score a text. It returns a [`Result`](/reference/result/).

`compound` is the main score. It runs from -1 (very negative) to +1 (very positive). The `label` comes from `compound`.

## Read the result

Keep using the same `$result`:

```php
$result->positive; // 0.594
$result->neutral;  // 0.406
$result->negative; // 0.0

$result->isPositive(); // true
$result->isNegative(); // false
$result->isNeutral();  // false
```

`positive`, `neutral` and `negative` show how the text splits. They add up to about 1. [Understanding the scores](/guides/understanding-scores/) explains each one.

The label is a [`Label`](/reference/label/) enum, so you can also use `match`:

```php
use Risan\Sentiment\Label;

$message = match ($result->label) {
    Label::Positive => 'Glad you liked it!',
    Label::Negative => 'Sorry to hear that.',
    Label::Neutral => 'Thanks for the feedback.',
};
```

## Export the result

```php
$result->toArray();
// [
//     'label' => 'positive',
//     'compound' => 0.6588,
//     'positive' => 0.594,
//     'negative' => 0.0,
//     'neutral' => 0.406,
// ]

json_encode($result);
// {"label":"positive","compound":0.6588,"positive":0.594,
//  "negative":0,"neutral":0.406}
```

A `Result` is `JsonSerializable`, so you can encode it directly. PHP writes the float `0.0` as `0` in JSON.

## Analyze Indonesian

```php
use Risan\Sentiment\Language;
use Risan\Sentiment\Sentiment;

$result = Sentiment::analyze(
    'Filmnya bagus banget!',
    Language::Indonesian,
);

$result->label;    // Label::Positive
$result->compound; // 0.623
```

You can also pass the language code:

```php
Sentiment::analyze('Filmnya bagus banget!', 'id');
```

An unknown code throws a `ValueError`:

```php
Sentiment::analyze('Hello', 'fr'); // throws ValueError
```

## Customize an analyzer

To add words or change the threshold, build an [`Analyzer`](/reference/analyzer/). Every `with*()` method returns a new analyzer. The original stays the same.

```php
use Risan\Sentiment\Analyzer;
use Risan\Sentiment\Language;

$analyzer = (new Analyzer(Language::Indonesian))
    ->withWords(['cuan' => 2.5])
    ->withoutWords(['kasar'])
    ->withThreshold(0.1);

$result = $analyzer->analyze('Investasinya cuan!');

$result->label;    // Label::Positive
$result->compound; // 0.5848
```
